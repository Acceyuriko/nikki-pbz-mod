# 暖暖换魂 mod 安装说明

这个 mod 把「影之刃零」主角魂的模型换成暖暖（Nikki）。

## 安装

1. 先关掉游戏。
2. 打开这个文件夹：`release\default-basic\ProjectPBZ\Content\Paks\~mods\`
3. 把里面这 3 个文件复制到游戏的 mod 目录：
   `E:\SteamLibrary\steamapps\common\PBZ\ProjectPBZ\Content\Paks\~mods\`
   - `zzz_Nikki_P.pak`
   - `zzz_Nikki_P.ucas`
   - `zzz_Nikki_P.utoc`
4. 启动游戏，进入有魂的场景就会看到暖暖。

## 注意

- 一次只放这一个 mod，不要和别的 mod 混在 `~mods` 里。
- 本版贴图是真实贴图，但衣服飘带、头发的基本物理摆动还没做，可能会穿模或不动。
- 动作是从魂重定向到暖暖的，比例不完全一样，可能有轻微变形。

## 卸载

把上面 3 个文件从 `~mods` 里删掉即可。

## 反馈

进游戏后看三件事：能不能正常进、会不会闪退、动作跟不跟手。然后把结果告诉制作者。
