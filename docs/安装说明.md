# 暖暖换魂 mod 安装说明

这个 mod 把「影之刃零」主角魂的模型换成暖暖（Nikki）。

## 安装

1. 先关掉游戏。
2. 打开这个文件夹：`release\default-phys\ProjectPBZ\Content\Paks\~mods\`
3. 把里面这 3 个文件复制到游戏的 mod 目录：
   `E:\SteamLibrary\steamapps\common\PBZ\ProjectPBZ\Content\Paks\~mods\`
   - `zzz_Nikki_P.pak`
   - `zzz_Nikki_P.ucas`
   - `zzz_Nikki_P.utoc`
4. 启动游戏，进入有魂的场景就会看到暖暖。

## 注意

- 一次只放这一个 mod，不要和别的 mod 混在 `~mods` 里。
- 薄纱、纱袖、蕾丝、丝袜这些透明部分，已经按模型烘进贴图的 alpha 通道，游戏里该透的会透。
- 宝石的「闪光」是游戏材质里的反光，静态贴图烘不出来，这部分会偏暗一点。
- 衣服裙摆、飘带、头发有基本物理摆动；动作大时仍可能轻微穿模。
- 本版把暖暖整体等比放大了一点，身高和魂接近。
- 动作是从魂重定向到暖暖的，比例不完全一样，可能有轻微变形。

## 卸载

把上面 3 个文件从 `~mods` 里删掉即可。

## 反馈

进游戏后看三件事：能不能正常进、会不会闪退、动作跟不跟手。然后把结果告诉制作者。
